## whoami

- BSc Computer Science, **York University** (Lassonde School of Engineering) — Sep 2023 to Sep 2027
- Co-Founder & Software Developer at **Clarus** — a healthcare workflow automation platform, part of the NSU startup cohort. Built a FastAPI rules engine that evaluates patient data against a clinical decision graph to auto-trigger voice calls, SMS, and referrals, plus an ElevenLabs + Twilio outbound call pipeline and a React Flow no-code workflow builder.
- Software Developer Intern at **Masjid Darul Iman** — building the community's React Native/Expo mobile app: sensor-fusion Qibla compass, WordPress REST API integration, and push notifications, serving 1,000+ members.

## 🏆 Featured Projects

| Project | Description |
|---|---|
| **[Clarus](https://github.com/Rahbir1518)** | Healthcare workflow automation platform (HackCanada 2026 winner). Clinicians configure outreach/follow-up logic through a drag-and-drop rules system; the backend reads lab results, evaluates clinician-authored rules, then an AI voice agent calls the patient and books the follow-up. |
| **Nervy** *(HackHive 2026)* | FastAPI + async WebSockets backend streaming live video for a multi-modal CV pipeline (MediaPipe/OpenCV) that scores eye contact and posture, plus a PyTorch/Hugging Face ASL-to-text engine for live captioning. |
| **Mimicoo** *(Hack the Valley 2025 — 6th place)* | AI pronunciation trainer using Parselmouth for infant speech-disorder risk analysis, with a React/TypeScript/FastAPI app delivering real-time fluency scoring. |
| **MDI Mobile App** | React Native/Expo app for Masjid Darul Iman serving 1,000+ members — sensor-fusion Qibla compass, WordPress REST API announcements feed, OneSignal/Expo push notifications, Supabase-backed volunteer scheduling. |
| **TCG Collection Tracker** | Native Android app (Kotlin, Jetpack Compose, Supabase) for tracking trading-card collections — price history, portfolio analytics, trade builder, and deck builder in progress. |
| **File Sorter/Launcher** | Electron desktop app that scans and categorizes local files (docs, games, music, design files) into a browsable, WizTree-style launcher with cover art. |
